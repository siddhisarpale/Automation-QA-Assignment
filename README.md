# Automation & QA Developer Take-Home Assignment

## Overview

This repository contains my submission for the Automation & QA Developer take-home assessment.

The assignment consisted of:

1. Web Application QA & Debugging
2. n8n API Integration Workflow

---

## Task 1 – QA Report

For the QA task, I tested the RealWorld demo application and explored the primary user flows including:

- User Registration
- Login
- Article Creation
- Article Editing
- Comment Management
- Logout

Based on my testing, I documented several usability, validation, and user experience issues along with a root-cause analysis for one selected issue.

The report is included in this repository.

---

## Task 2 – n8n Workflow

For the automation task, I created an n8n workflow that:

- Retrieves cryptocurrency data from the CoinGecko API
- Processes and filters the returned data
- Fetches additional details through a second API request
- Produces structured output within n8n

The workflow export and supporting documentation are included in this repository.

---

## Notes

My professional background is primarily in web development. Prior to this assessment, I had not worked with n8n or automation-focused workflow tools.

As part of this assignment, I learned the fundamentals of n8n, set up a local environment, explored API integrations, and implemented a working workflow within the available time.

While there are areas that could be extended further (such as additional error handling, notification channels, and monitoring workflows), I focused on demonstrating my problem-solving approach, ability to learn unfamiliar tools quickly, and understanding of the assignment requirements.
